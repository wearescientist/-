X Super Assistant 隐私政策

最后更新日期：2026-05-13

一、扩展用途

X Super Assistant 是一款面向 X（Twitter）运营互动场景的 Chrome 侧边栏助手。它用于在用户授权并主动启动功能后，帮助用户管理私信群组互动、KOL 24 小时推文回复、评论互动、数据库推文回复、AI 回复配置、节奏控制和执行记录。

二、我们处理的数据

为提供核心功能，扩展可能在用户主动使用时处理以下数据：

  • X 页面中的推文、评论、主页、私信群组页面内容和推文链接。
  • 用户维护的 KOL 列表、群组选择、已处理记录和执行日志。
  • 用户自行填写的 AI 服务配置、API Key、Google Sheets 链接和 Apps Script URL。
  • 用户指定的 Google Sheets 表格数据。

三、数据使用方式

这些数据仅用于提供扩展的核心功能，包括读取页面内容、生成 AI 回复文本、执行用户主动启动的互动流程、保存本地配置与执行记录、读取 Google Sheets 表格以及通过用户配置的 Apps Script 写入表格。

四、数据存储

扩展配置、任务状态、执行记录和去重记录主要保存在用户浏览器本地的 Chrome 扩展存储中。用户可通过浏览器扩展管理、清理浏览器数据或卸载扩展来删除本地数据。

五、第三方服务

当用户配置并使用 AI 服务时，相关推文或评论内容可能会发送至用户自行配置的 AI 服务商，例如 OpenAI、DeepSeek、Grok、Gemini 或兼容接口。

当用户配置并使用 Google Sheets 或 Apps Script 功能时，相关数据可能会发送至用户指定或授权的 Google 服务。

用户应确认自己使用的第三方服务符合自身隐私和合规要求。

六、数据共享与出售

我们不会出售用户数据，不会将用户数据用于广告画像、信用评估或与扩展单一用途无关的目的。除用户主动配置的第三方服务调用外，我们不会将用户数据转移给第三方用于非核心功能目的。

七、远程代码

扩展不会从远程服务器下载并执行 JavaScript 或 WebAssembly 代码。扩展使用的脚本随扩展包一起发布。远程请求仅用于访问用户配置的 AI 服务、Google Sheets 或 Apps Script 数据接口。

八、用户控制

用户可以随时修改或删除扩展中的配置，例如 API Key、Google Sheets 链接、KOL 列表、群组选择和本地记录。用户也可以通过 Chrome 扩展管理页面停用或卸载扩展。

九、政策更新

如果扩展功能或数据处理方式发生变化，本隐私政策可能会更新。更新后的政策会替换当前版本。

十、联系

如需支持，请通过 Chrome Web Store 商品页提供的支持方式联系发布方。
